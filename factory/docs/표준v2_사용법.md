# 표준 v2 사용법 (11/11)
표준 설명·근거: `docs/제작표준_v2_제미나이프로토콜.md` · 수치: `standard_v2.json` · 예시 기획: `samples/v2/`

## 1. 한 줄 사용법
| 하고 싶은 것 | 명령 |
|---|---|
| 편성표 보기 | `python3 make_today.py --templates-dir templates_v2 --list` |
| 요일 틀로 만들기(렌더 + 자동 점검) | `python3 make_today.py --templates-dir templates_v2 --day 월 --slot 저녁 --fill templates_v2/fills/fill_월_A.json` |
| 렌더 없이 확인만 | 위 명령 끝에 `--dry` |
| 게시 꾸러미까지(쇼츠만) | 위 명령 끝에 `--package` (예약 19:00, 템플릿 길이 넘으면 멈춤) |
| 쇼츠 A 계열 직접 | `python3 expose_factory.py samples/v2/expose_anwon_test.json [결과폴더]` |
| 쇼츠 B 계열 직접 | `python3 stagemix_factory.py samples/v2/pulse58_formtest.json [결과폴더]` |
| 몰아보기 직접 | `python3 longform_factory.py samples/v2/molabogi_anwon_test.json [결과폴더]` |
| 점검만 다시 | `python3 check_standard.py 기획.json 결과.mp4` |
- fill 의 `"길이": 40` → 같은 계열 40초 판(58-N→40-N, 58-M→40-M).
- 모든 공장은 렌더 뒤 `check_standard.py` 를 자동으로 돌려 ✅/❌ 를 출력한다.

## 2. 쇼츠 A 계열 기획(58-N / 40-N) — expose_factory.py
```json
{"template":"expose","shorts_template":"58-N","out":"이름","title":"경상도 둘의 (첫 서울)",
 "series_name":"덕심저장소 · 안원잘부 사투리 편","source_line":"출처 · 채널 (제작사)",
 "clean_ranges":[[252,319],[362.4,449]],"forbidden_ranges":[[362.6,373.0]],
 "brand":{"title":"안원잘부 사투리 편","sub":"덕심저장소 몰아보기 · 화·토 저녁 7시"},
 "clips":[{"file":"원본.mp4","in":421.0,"out":424.0,"role":"hook",
           "zooms":[{"at":2.4,"x":0.38,"y":0.35,"scale":1.8,"hold":0.55}],
           "bleeps":[{"at":5.95,"dur":0.55}],"sfx":[{"at":1.0,"name":"crow"}],
           "captions":[{"at":0.15,"dur":2.2,"text":"(첫 서울 = 관광버스)","style":"bracket"}]}],
 "narration":[{"at":5.2,"text":"거제 원이, 경주 제나.","file":"veda/01.mp3"}],
 "outro":{"ask":"(여러분의 첫 서울은?)","next":"[화·토 몰아보기에서]","frame":{"file":"원본.mp4","t":446.6}},
 "thumb":{"quote":"우리 입장에서 용인도 서울이야","hook":"첫 서울 = (에버랜드?)","tag":"안원잘부","frame":{"file":"원본.mp4","t":409.6},"zoom":[0.45,0.42,1.7]},
 "post":{"title":"… #shorts","desc":"…"}}
```
| 칸 | 뜻 | 기본 |
|---|---|---|
| `shorts_template` | 58-N(58.0초) / 40-N(40.0초) | 58-N |
| `clips[].role` | 58-N: hook·twist·expose1·expose2·brand / 40-N: hook·body. 역할 합이 구간표와 ±0.05초로 맞아야 함 | 필수 |
| `clips[].in/out` | 원본 구간(초). 광고·금지 구간 안 됨 | 필수 |
| `clips[].layout` / `x_center` | fit(가운데 통째 + 위아래 흐린 멈춘 배경) / crop(세로 꽉) | fit |
| `clips[].zooms` | 크래시 줌 `{at,x,y,scale,hold}` (x·y 원본 비율, 0.15초 급확대) | 없음 |
| `clips[].bleeps` | 삐- `{at,dur}` 원음 줄이고 1kHz | 없음 |
| `clips[].sfx` | 효과음 `{at,name:"crow"}` 또는 `{at,file}` | 없음 |
| `clips[].captions` | `{at,dur,text,style,pos?,color?}` style: bracket(괄호 드립) · situation([상황]) · big · sfx | 없음 |
| `clips[].audio_lead` | 다음 장면 소리 먼저(J컷) | 0.5 (첫 클립 0) |
| `narration` | Veda 내레이션 `{at(영상 전체 초),file?,text}` — 파일 없으면 자막 | 없음 |
| `outro` | 아웃트로 5초 `{ask,next,banner?,frame}` | 편성 배너 자동 |
| `thumb` | v2 썸네일 `{quote(실제 대사),hook,tag,frame,zoom?,x_center?}` | 첫 클립 장면 |
| `clean_ranges` / `forbidden_ranges` | 본편 구간 / 쓰면 안 되는 구간 → 점검기 | 없음 |
| `test_label` | 왼쪽 위 빨간 표시(시험본) | 없음 |

## 3. 쇼츠 B 계열 기획(58-M / 40-M) — stagemix_factory.py
```json
{"preset":"pulse58","template":"pulse58","shorts_template":"58-M","out":"이름",
 "song":{"file":"노래.m4a","start":42.0},"bpm":124,
 "sources":[{"file":"쇼케이스.mp4","sync":30.0,"label":"쇼케이스"}],
 "title":"…","source_line":"출처 · …","copyright_checked":true,
 "outro":{"ask":"(가장 좋았던 무대는?)","next":"…","frame":{"file":"…","t":222.0}}}
```
| 칸 | 뜻 | 기본 |
|---|---|---|
| `shorts_template` | 58-M(소스 8개 이상) / 40-M(소스 4~6개) | 58-M |
| `sources[].sync` | 노래 start 와 맞는 그 영상의 시각 | 필수 |
| `bpm` / `beat_phase` | 박자. 없으면 ffmpeg 소리 → numpy 온셋으로 추정(결과에 bpm·신뢰도 출력) | 추정 |
| `song_volume` | 노래 크기(마지막 loudnorm) | 1.0 |
| `copyright_checked` | 저작권·팬캠 양해 확인 | false면 꾸러미 ❌ |

## 4. 몰아보기(롱폼) — longform_factory.py v2.2
기존 v2.1 칸(opening·chapters·scenes·subs·narration·sfx·music_cut·ending·product_cards·rewind …)을 그대로 쓰고, 아래가 더해졌다.
| 칸(장면 안) | 뜻 |
|---|---|
| `subs` 4번째 칸 `"bracket"` / `"situation"` / `"narr"` | 괄호 드립 / [상황] 왼쪽 위 상자 / 내레이션 자막(위 가운데). 5번째 칸 `[x,y]` 자리 |
| `reacts:[{at,sec,text,name}]` | 오른쪽 아래 「동네 형」 일러스트 아이콘 + 말풍선(실존 인물 얼굴 없음) |
| `zooms:[{at,x,y,scale,hold}]` | 크래시 줌 |
| `bleeps:[{at,dur}]` | 삐- |
| `sfx:[{at,name:"crow"}]` | 이름 효과음(합성 까마귀) |
| `narration:[{at,text}]` (file 없음) | 자막으로 대신(파일이 생기면 소리 + 덕킹) |
| 맨 위 `template:"molabogi"`, `thumb_v2:{quote,hook,tag,frame,zoom}`, `test_sections_check` | 표준 점검·v2 썸네일·90초 시험 조각 점검 |

## 5. 점검기(check_standard.py)가 보는 것
| 항목 | 기준(standard_v2.json) |
|---|---|
| 길이 | 58-N·58-M 58.0초 / 40-N·40-M 40.0초, ±0.05 (영상·소리 모두) |
| 해상도·소리 | 쇼츠 1080x1920·48kHz / 롱폼 1920x1080 |
| 구간 순서·시간 | 템플릿 구간표(쇼츠 A 계열은 클립 역할로 실제 계산) |
| 아웃트로 | 5초 |
| 소스 수 | 58-M 8개 이상 / 40-M 4~6개 |
| 내레이션 | N 판: 자리 있음(Veda 파일 수 표시) / M 판: 내레이션 없음 |
| 정지 화면 | 8초 넘게 멈춘 곳 없음(freezedetect) |
| 금지어 | 「뭐하노」 — 제목·썸네일·자막·말풍선·게시 문구 |
| 출처 | source_line / credit 있음 |
| 금지·광고 구간 | forbidden_ranges 와 겹치지 않음, clean_ranges 안 |
| 술·담배·도박·성인 | 클립·장면 메모·상품 카드 이름 |
| 따옴표 대사 | 우리 자막·말풍선에 큰따옴표 없음(드립은 괄호) |
| 기준서 v1(롱폼) | 오프닝 하이라이트 약 3초, 질문 20~32초, 엔딩 |

## 6. 꾸러미(package.py) 바뀐 점
- v2 쇼츠는 모든 칸(유튜브·인스타·틱톡·X·스레드)에 **같은 파일 하나**. 템플릿 길이(58.0/40.0)를 0.05초라도 넘으면 꾸러미를 만들지 않고 멈춤.
- 예약 시각 19:00(업로더 시간대 「저녁7시」). 옛 5줄 점검표 대신 표준 v2 점검 결과(spec 의 `_v2_check`)를 씀.
- 몰아보기(롱폼)는 꾸러미 대상 아님 → 멈추고 안내.

## 7. 주문판 주문으로 만들기 (`--order`)
주문판(`order/index.html`)의 주문 1건 JSON `{format, type, area, sensitive, subs[], moods[], free, at, status}` 을 그대로 넣는다.
```
python3 make_today.py --order 주문.json                    # 재료 빈칸 파일(재료_빈칸.json)을 만들고 멈춤
python3 make_today.py --order 주문.json --fill 재료.json   # 렌더 + 자동 점검 (--dry / --package 가능)
```
| 규칙 | 내용 |
|---|---|
| type | 쇼츠 58-N·58-M·40-N·40-M / 롱폼 L8-N(약 8분 내레이션 몰아보기)·L8-M(8분 무대·음악 모음)·L4-N(약 4분 가벼운 내레이션)·L4-M(4분 가벼운 무대 모음) — `standard_v2.json` shorts_templates·long_templates |
| at | 요일·시각(예약). 없으면 틀 기본(19:00) |
| sensitive=true | **렌더 전에 멈춤(종료 코드 3)**. 대표가 확인하고 주문 status 를 `"approved"` 로 바꾸면 진행 |
| moods(최대 3) | 연출 프리셋으로 바뀌어 spec `mood_preset` 에 기록 → 점검기가 기획에 들어갔는지 ℹ️/⚠️ 로 알림(통과 여부엔 안 들어감) |

| 분위기 묶음 | 연출 프리셋 |
|---|---|
| 웃음(레전드·웃참·킹받는·대환장·폭로·드립 자막) | 괄호 자막 · 효과음 · 크래시 줌 |
| 감동(눈물·감동 실화·뭉클·역주행·언더독·수상소감) | 음악 끊기 · 느린 컷(4~6초) · 감정 자막 |
| 짜릿(사이다·참교육·반전·역대급·미친 무대·소름) | 빠른 컷(0.5~2초) · 셰이크 |
| 설렘(케미·로맨스·청순·비주얼·힐링) | 감정 자막 · 디졸브 (Claude 제안, 대표 확인) |
| 몰입(몰아보기·결말 포함·비하인드·최초 공개·직캠 4K) | 챕터 · J컷 |
| 정보(정리·TOP 순위·숫자로 보기·상식·근황) | 순위 카드 · 숫자 자막 |

## 8. 길이 직접 입력 (프리셋 + 숫자)
| 형식 | 프리셋 | 직접 입력 |
|---|---|---|
| 쇼츠 | 58 / 40 / 25초 | 숫자(15~58초). 40 이하는 40-x 구간표, 넘으면 58-x 구간표를 **비례 배분**(훅 3초·아웃트로 5초 고정). 58초 넘으면 make_today·점검기·package 가 멈춤 |
| 롱폼 | 약 8 / 4 / 6 / 20 / 30분 | 분 숫자 → `length_sec`, 점검 범위 ×0.85~×1.25 |
| 카드 | 7 / 10 / 12 / 20장 | 20장까지 |
- 기획 json 에 `"length_sec": 25`, fill·주문에 `"길이": 25` / `"len": 25`.
- 예: 25초 → 40-x 구간표가 [0~3 훅][3~20 본문][20~25 아웃트로]로 바뀜. 50초 58-N → [0~3][3~4.67][4.67~21.47][21.47~38.27][38.27~45][45~50].

## 9. 제작 11단계 파이프라인 (pipeline.py)
```
python3 pipeline.py scenario 주문.json   # 4 시나리오 초안(scenario.md/json) — 실제 장면·실제 대사 칸
python3 pipeline.py plan     주문.json   # 5 재료 수·컷 목록·연출 프리셋
python3 pipeline.py draft    주문.json   # 6 첫 렌더(+ 내레이션 원고 500자씩, 'Veda 생성 필요')
python3 pipeline.py check    주문.json   # 7 점검기 + 3초 모음 이미지 → 8 대표 컨펌 대기
python3 pipeline.py confirm  주문.json   # 8 대표 컨펌(주문판 버튼과 같음 — 대표만)
python3 pipeline.py final    주문.json   # 9 완성 + 자막 srt·번역 원고(langs) + 더빙 원고·오디오 자리(narrLangs)
python3 pipeline.py verify   주문.json   # 10 싱크(무음 vs 자막)·길이·금지어
python3 pipeline.py package  주문.json   # 11 플랫폼별 묶음(업로드 안 함)
python3 pipeline.py status   주문.json
```
- 결과: `out/<주문 id>/` (state.json 에 stage·issues·files·history). 순서를 건너뛰면 멈춤. 컨펌 전 final 은 멈춤. 민감 주문은 시나리오부터 멈춤.
- 내레이션 음성: `out/<id>/narration/<초>.mp3`(예 `5.2.mp3`) 로 넣으면 draft/final 에서 자동으로 입혀짐(원음 −14dB 덕킹).
- 번역: final 이 만든 `번역원고_<언어>.txt` 오른쪽 칸을 채워 `번역_<언어>.txt` 로 저장 → final 다시 → `final.<언어>.srt`.
- 더빙: `dub/<언어>/TTS_원고.txt` 로 무료 Gemini TTS 생성 → 같은 폴더에 오디오 → final 다시 → `final_<언어>_dub.mp4`.
- 언어 10개: en 영어 · ja 일본어 · zh-Hans 중국어 간체 · zh-Hant 대만 번체 · es 스페인어 · pt 포르투갈어 · id 인도네시아어 · th 태국어 · vi 베트남어 · fr 프랑스어.
- 카드릴스: shorts_factory 의 cards 틀로 연결(spec 의 template "cards"). 카드뉴스: 저장소에 카드 만들기 스크립트가 없어 **TODO**.
