# 롱폼 공장(longform_factory.py) 옵션 정리

사용법
- 시험 재료 만들기: `python3 longform_factory.py --test-media samples/_test`
- 영상 만들기: `python3 longform_factory.py samples/sample_long_v2.json`
- 결과: `samples/out/<out>.mp4`(1920x1080, 30fps) · `_thumb.jpg`(1280x720) · `.srt` · `_설명란.txt` · 점검표(화면 출력)
- 시각(초) 기준: 장면 안 옵션은 **그 장면 시작부터**, 맨 위 옵션은 **영상 전체 기준**.
- 「기준서 추가」 표시 = 덕심저장소 롱폼 기준서 v1 추가 4개(11/11).

## 3. 장면 옵션 (`scenes` 안)

| 옵션 | 뜻 | 기본값 / 예 |
|---|---|---|
| `file` | 영상 파일 | 영상 장면 필수 |
| `in` / `out` | 쓸 구간(초) | 필수 |
| `image` | 사진 장면(SNS 캡처 등). 가운데 사진 + 흐린 배경 | 없음 |
| `sec` | 사진 장면 길이(초) | `4` |
| `layout` | `"horizontal"` 가로 / `"vertical"` 세로(가운데) / `"split"` 가로+세로 나란히 / `"blur"` 흐린 배경만 | 가로(사진은 세로) |
| `file2` / `in2` | split 일 때 오른쪽 세로 영상·시작 초 | 없음 |
| `side_left` | 세로 화면 왼쪽 정보 카드(글, 목록, `{tag, title, lines}`) | 없음 |
| `side_right` | 세로 화면 오른쪽 카드 또는 댓글 말풍선 목록 `[{name, text, at}]` | 없음 |
| `subs` | 자막 `[시작, 끝, "문장", 모양, 위치]` (아래 3-1) | `[]` |
| `comments` | 댓글 띄우기 `[{at, sec, name, text}]` | `[]` |
| `credit` | 오른쪽 아래 출처 표기 | 없음(점검표 경고) |
| `own` | 자체 제작이라 출처 표기 필요 없음 | `false` |
| `volume` | 원본 소리 크기 | `1.0` |
| `audio_lead` | J컷: 다음 장면 소리 먼저(초) | `0` |
| `audio_tail` | L컷: 앞 장면 소리 이어서(초) | `0` |
| `transition` | 들어오는 전환 강제: `"cut"` / `"dissolve"` | 자동 |
| `narration` | 장면 안 내레이션 `{file, at, volume}` (나오는 동안 덕킹) | 없음 |
| `sfx` | **기준서 추가** 같은 시각 효과음 `[{at, file, volume}]` | 없음 |
| `music_cut` | **기준서 추가** 장면 안 기준 음악 끊기 `[{at, sec}]` | 없음 |
| `long_ok` | 긴 장면 경고 끄기 | `false` |
| `product_cards` | **상품 카드** 장면 안 기준(장면 시작부터) `[{at, sec, name, price, url, label}]` (아래 7번) | 없음 |

### 3-1. 자막 모양 (`subs` 4번째 칸)

| 모양 | 생김새 | 5번째 칸(위치) |
|---|---|---|
| `"sub"`(기본) | 흰 굵은 고딕, 화면 아래, 어두운 띠. `*별표*` 단어는 노란색 | 없음 |
| `"big"` | 크게 가운데(하이라이트 대사·주제 한 줄) | 없음 |
| `"ask"` | 노란색 가운데(엔딩 질문) | 없음 |
| `"question"` | 노란색 위쪽 띠(오프닝 질문) | 없음 |
| `"emotion"` | **기준서 추가** 감정 자막: 작게(42), 화면 옆쪽(아래 자막 위), 기울임, 연분홍. 0.35초 페이드 인·아웃. 인물 마음을 대신 말하는 한 줄. `*별표*`는 흰색 | `"right"`(기본) / `"left"` |
| `"sfx"` | **기준서 추가** 효과음 자막: 짧은 의성어, 노란 굵은 글씨 살짝 기울임, 0.3초 팝(작게→크게→제자리). 자막 파일(.srt)에는 `[쿵!]`처럼 들어감 | `[x, y]` 화면 비율, 기본 `[0.5, 0.3]` |

## 4. 오프닝 (`opening`)

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `highlight` | 0~3초 하이라이트 장면 `{file, in, out, line, credit}` — `line`은 크게 가운데 | 없음 |
| `question` | 노란 질문 자막(위쪽) | 없음 |
| `question_at` | 질문이 나오는 시각(영상 전체 기준) | `25` |
| `question_sec` | 질문 자막 길이(초) | `4` |

## 5. 엔딩 (`ending`)

순서: 마지막 장면 흐리게 → 주제 한 줄 → 질문 → **결심 한 줄(검은 화면)** → 끝 화면 → 출처 화면

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `line` | 주제 한 줄(크게 가운데) | 없음 |
| `line_sec` | 주제 한 줄 길이(초) | `3` |
| `ask` | 질문 자막(노란색 가운데) | 없음 |
| `ask_sec` | 질문 길이(초) | `3.5` |
| `volume` | 엔딩 배경 장면 원본 소리 크기 | `0.6` |
| `resolve` | **기준서 추가** 결심 한 줄: 검은 화면 위 흰 글씨가 페이드인 후 끝 화면으로 이어짐. `*별표*` 노란색 | 없음(점검표 ❌) |
| `resolve_fade` | 결심 한 줄 페이드인 길이(초) | `2.0` |
| `resolve_sec` | 결심 화면 전체 길이(초, 페이드+0.5초보다 짧으면 늘림) | `3.5` |
| `next` / `next_date` | 끝 화면 다음 편 안내 | 없음 |

## 6. 효과음·음악 끊기 세부

| 옵션 | 칸 | 뜻 | 기본값 |
|---|---|---|---|
| `sfx` | `at` | 효과음 시작 시각(장면 안이면 장면 기준) | `0` |
| | `file` | 효과음 파일 | 필수 |
| | `volume` | 크기(배율). 덕킹·음악 끊기 영향 없음 | `1.0` |
| `music_cut` | `at` | 정적 시작 시각 | `0` |
| | `sec` | 배경음악 0 유지 길이(초) | `1.0` |
| | `fade_out` | 내려가는 시간(초, `at` 직전) | `0.12` |
| | `fade_in` | 돌아오는 시간(초) | `0.6` |

- 음악 끊기는 **배경음악만** 끊는다(원본 소리·내레이션·효과음은 그대로). 원본 소리가 없는 사진 장면 등에 두면 완전한 정적이 된다.
- 배경음악이 없으면 점검표에 경고가 뜬다.

## 7. 상품 카드 (`product_cards`, 언더독스토리 벤치마킹 11/11)

영상 중간중간 **왼쪽 아래**에 QR 상품 카드(쿠팡 파트너스 등 제휴 링크)를 띄운다. 맨 위에 두면 영상 전체 기준, 장면 안에 두면 그 장면 시작부터 센다.

| 칸 | 뜻 | 기본값 |
|---|---|---|
| `at` | 나타나는 시각(초) | `0` |
| `sec` | 보이는 길이(초, 최소 1) | `6` |
| `name` | 상품명(카드에 2줄까지, 넘치면 …) | 필수 |
| `price` | 가격 글(예 `"12,900원"`) | 없음 |
| `url` | 상품 링크 — QR로 들어감(바이트 모드·오류정정 M, 213바이트까지) | 필수 |
| `label` | 카드 맨 아래 안내 한 줄 | `"QR 찍고 상품 보기"` |

- 모양: 흰 둥근 상자 + 왼쪽 QR + 「**광고 · 제휴 링크**」 표시(항상, 끌 수 없음) + 상품명·가격·안내. 0.3초 왼쪽에서 슬라이드 인, 끝 0.3초 페이드 아웃.
- 자리: 그 시간에 떠 있는 자막·감정 자막·출처·말풍선·옆 정보 패널·다른 상품 카드와 **겹치지 않을 때까지 위로** 올린다. 왼쪽이 막히면 오른쪽 아래(오른쪽에서 슬라이드 인). 세로 레이아웃에서도 카드 폭(약 530px)이 세로 영상 왼쪽 빈자리 안에 들어감.
- 설명란: 맨 위에 `■ 상품 링크 (광고 · 제휴 링크)` 목록(이름·가격·나오는 시각·링크). url에 `coupang`이 있으면 그 위 첫 줄에 고지 문구 「이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.」 자동.
- 점검표: `상품 카드: N개, 광고 표시 ✅` · 쿠팡 고지 ✅ · 판매 제한 품목(주류·담배·도박·성인 단어가 상품명·안내에 있으면 ❌) · 겹침 없음(자리가 없으면 ❌). 끝 화면·출처 화면 위에 걸치면 ⚠️.
- 실제 쿠팡 링크는 짧은 링크(`https://link.coupang.com/a/…`)를 쓰면 QR이 작고 잘 읽힌다.
- QR 만드는 곳: `factory/qr.py` (순수 파이썬, 외부 라이브러리 없음). 단독 사용: `python3 qr.py "https://…" qr.png`
