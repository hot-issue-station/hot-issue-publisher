# 게시 꾸러미 (package.py) 사용법

빈칸(fill.json)만 채우면 **영상 → 썸네일 → 5곳 게시 문구 → 출처 기록 → 점검표 → 유튜브 예약 계획**까지 한 번에 나온다.
아무 사이트에도 올리지 않는다. 올리는 것은 업로더(확인 모드)와 대표가 한다.

## 한 번에 (렌더 + 꾸러미)

```
python3 make_today.py --day 수 --slot 저녁 --fill fill.json --package
```
- `--package` 를 빼면 예전과 똑같이 영상·썸네일·게시문구만 만든다(기본값 그대로).
- 함께 쓸 수 있는 것: `--outbox 폴더`(기본 `factory/outbox`), `--date 2026-11-18`, `--sites youtube,tiktok,meta,x`, `--ai`

## 이미 만든 결과 폴더로 꾸러미만

```
python3 package.py out/20261111_수_저녁
```

## 꾸러미 폴더

`outbox/<예약날짜>_<요일><시간대>_<곡>/` 예) `outbox/20261111_수저녁_PULSE/`

| 파일 | 내용 | 한도(넘으면 줄이고 경고) |
|---|---|---|
| video.mp4 | 다섯 곳 공통 영상 | — |
| thumb.jpg | 썸네일(유튜브 2MB 이하로 저장) | 2MB |
| youtube.txt | 제목 · 설명(출처 줄 + 해시태그) · 태그 · 첫 댓글(고정) | 제목 100자 · 설명 5000자 · 태그 합계 500자 |
| instagram.txt | 릴스 캡션(설명 + 질문 + 출처 + 해시태그) | 2200자 · 해시태그 30개 |
| tiktok.txt | 제목 + 설명 + 해시태그 | 2200자 |
| x.txt | 짧은 글 + 해시태그 | 280 (한글·이모지 2, 영문·숫자 1, 링크 23) |
| threads.txt | 설명 + 질문 + 출처 + 주제 태그 1개 | 500자 |
| sources.md | 출처·확인 기록, 영상 속 숫자 대조표(☐ 체크) | — |
| checklist.txt | 공장 점검표 + 글자 수 표 + 운영 규칙 + 승인 3단계 + 올리는 곳 | — |
| upload_plan.json | 업로더 계획(확인 모드, 기본 유튜브만) | — |
| spec.json | 만들 때 쓴 기획(다시 계획할 때 씀) | — |

- 한도를 넘으면 **해시태그를 뒤에서부터 빼고**, 그래도 넘으면 **본문 끝을 「…」로 자른다.** 줄인 것은 checklist.txt 「줄인 것」에 남는다.
- `#shorts` 는 유튜브에만 붙고 나머지 네 곳에서는 뺀다.
- 대표가 `out/<이름>_게시문구.txt` 의 유튜브 제목·설명·첫 댓글을 고쳤으면 고친 글을 쓴다.
- `--ai`: 글이 한도를 넘을 때 AI 교환대(ai_router)로 줄인 **초안**을 쓴다. 키가 없거나 답이 한도를 넘으면 건너뛰고 기계적으로 자른다.

## 예약 시각

틀의 시간대 그대로: **아침 07:30 · 점심 12:00 · 저녁 18:30 (서울)**. 날짜는 **틀 요일의 가장 가까운 날**(지금부터 20분 이상 남은 때).
예) 수요일 17시에 `수_저녁` → 오늘 18:30 / `목_아침` → 내일 07:30. `--date` 로 바꿀 수 있다(요일이 다르면 알림).

## 업로더로 넘기기 (대표 데스크톱)

- `uploader\run_package.bat` 위에 `upload_plan.json` 을 끌어다 놓기 (= `python uploader/run.py --plan .../upload_plan.json`)
- 계획 파일을 다시 점검(파일·예약 시각·한도·확인 모드)한 뒤, 통과하면 **최종 [예약] 단추 직전에서 멈춘다.** 단추는 대표가 직접.
- 처음엔 **유튜브만** 들어 있다. 틱톡·인스타·X를 넣으려면 `--sites youtube,tiktok,meta,x` 로 다시 만든다. 스레드는 업로더가 없어 손으로.

## 글을 고친 뒤

꾸러미의 txt 를 직접 고쳤으면 계획·점검표만 다시 만든다(영상은 그대로):
```
python3 package.py --replan outbox/20261111_수저녁_PULSE
python3 package.py --check outbox/20261111_수저녁_PULSE/upload_plan.json   # 계획 파일 점검만
```

## 멈추는 경우

- 공장 점검표에 ❌ (끝 화면·배경음악·출처·숫자 확인·썸네일/제목/소개글/첫 댓글, 교차편집은 저작권 확인·무대 소스 8개)
- 예약 시각이 지났거나 20분 안, 파일 없음, 확인 모드가 아님, 글자 수 한도 초과
- 이때 꾸러미는 만들어지지만 업로더 계획은 `ok: false` 라 업로더가 진행하지 않는다.

## 사람이 하는 것 (자동으로 하지 않음)

- 승인 3단계: 주제 → 최종 문구(각 txt) → 발행 직전
- sources.md 숫자 대조 체크, 민감 이슈 여부, 출처 2곳 미만이면 자동 게시하지 않음
- 유튜브 첫 댓글: 공개된 뒤 달고 고정
