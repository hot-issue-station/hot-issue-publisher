# 업로드할 때마다 챙기는 첫 댓글 (대표 결정 2026-11-04 13:08~13:13)

모든 업로드(유튜브 쇼츠·롱폼, 인스타 릴스)에서 게시 직후 **우리 계정 첫 댓글**을 남긴다. 유튜브는 첫 댓글을 **고정**한다.
이유(대표): 먼저 댓글을 남겨도 된다는 시작 글이 있으면 사람들이 그다음에 댓글을 단다.

## 첫 댓글에 꼭 들어갈 세 가지
1. **소재에 맞는 응원 유도**: 스포츠면 "응원하는 팀에게 격려 한마디", 아이돌이면 "좋아하는 마음을 응원으로".
2. **건강한 댓글 문화**: 서로 존중하고, 상대 팀이나 다른 그룹·선수·아티스트를 깎아내리지 않는 매너 있는 댓글을 정중하게 부탁한다.
3. **구독·좋아요·알림 설정 부탁**: 인스타는 팔로우·좋아요로 쓴다.

말투는 존댓말로, 이모지는 2~3개만 쓴다. 과장하거나 강요하지 않는다.

## 문구 예시
- 스포츠(한국시리즈 2차전, 11/4):
  "⚾ 오늘 18:30 한국시리즈 2차전! 응원하는 팀에게 격려 한마디를 댓글로 남겨 주세요 📣 / 서로 다른 팀을 응원해도 모두 같은 야구팬이에요. 상대 팀과 선수를 존중하는 매너 있는 댓글 부탁드려요 🙏 / 영상이 좋으셨다면 구독·좋아요·알림 설정도 부탁드려요! 매일 이슈를 짧고 따뜻하게 정리해 드릴게요 😊"
- 아이돌·팬덤(리센느 등, 지난 쇼츠에 단 문구):
  "💜 함께 응원해 주셔서 고마워요! / 서로를 존중하는 따뜻한 댓글 문화를 함께 만들어 가요 🙏 다른 그룹이나 아티스트를 깎아내리는 말 대신, 좋아하는 마음을 응원으로 남겨 주세요. / 영상이 좋으셨다면 구독·좋아요·알림 설정도 부탁드려요! 매일 이슈를 짧고 따뜻하게 정리해 드릴게요 😊"
- 사건·사고·정치: 응원 문구는 넣지 않는다. 대신 "서로 다른 생각도 존중하는 차분한 댓글 부탁드려요"와 구독 부탁만 넣는다.

## 방법
### 유튜브 (Claude in Chrome)
1. 시청 페이지 `youtube.com/watch?v=<ID>`를 연다(쇼츠도 watch 주소로 연다).
2. 영상을 멈추고 아래로 스크롤해 `#simplebox-placeholder`를 누른다.
3. `#contenteditable-root`에 `execCommand('insertText')`로 문구를 넣고 `ytd-commentbox #submit-button`을 누른다.
4. 고정:
   1. 우리 댓글의 `#action-menu button`을 누른다.
   2. 메뉴에서 '고정' 항목을 누른다. 메뉴는 화면에 고정된 팝업이라 `offsetParent` 대신 `getClientRects().length`로 보이는지 확인한다.
   3. 확인 창의 `yt-button-renderer#confirm-button button`을 누른다.
5. 이미 다른 고정 댓글이 있으면 덮어쓰지 않고 댓글만 남긴다. 이미 같은 문구의 댓글이 있으면 건너뛴다.

### 인스타
1. 게시 직후 `/p/<ID>/`를 연다.
2. '댓글 달기' 칸을 클릭해 실제 키보드로 입력한 뒤 [게시]를 한 번만 누른다.
3. 목록이 바로 새로 고쳐지지 않아도 다시 누르지 않는다. 11/4에 두 번 눌러 중복 댓글이 생겼다. 새로고침해서 확인한다.

### 틱톡·X·스레드
- 첫 댓글은 선택이다. 같은 문구를 남겨도 되지만, 스레드는 대표가 직접 맡는다.

## 업로드 순서표에 넣기
사이트별 확인표에 "첫 댓글(고정)" 칸을 두고 문구를 함께 보여 준 뒤, 게시와 같은 승인으로 바로 단다.
