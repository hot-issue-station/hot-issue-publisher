# 오메가컷 (OmegaCut) — 우리만의 롱폼 → 요약 쇼츠 도구
이름·방향: 대표 결정 2026-11-02 14:18~14:20. 알파컷 같은 자동 편집을 벤치마킹하되 "양산형 느낌을 지우고 사람의 정성이 들어가게".

## 원칙
- 허락받은 영상만 넣는다(유튜브 자동 다운로드는 하지 않음 — 약관·차단). 추가 비용 0원.
- AI는 초안, 장면 선택과 '이슈브리프 한 줄'은 사람(대표)이 정한다.
- 음악은 수노 구독 중 만든 9곡(해지 후에도 권리 유지, 결제 영수증 보관) + 합성곡.

## 단계
1. 후보 뽑기 `scripts/pick_scenes.py <영상> <폴더>` — 소리 크기·갑자기 커짐·장면 전환 밀도로 후보 10개 + 번호 붙은 모음 이미지(sheet.jpg). ✅ 1차 완성(11/2)
2. 대표가 휴대폰에서 번호 5~7개 선택 + 장면마다 '이슈브리프 한 줄'(확인된 사실) — (다음)
3. 이야기 순서로 이어 붙이기: 궁금증 → 장면들 → 마지막 한 방 — (다음)
4. 쇼츠 기본 틀 입히기(두 줄 제목·노란 자막·양옆 글자·테이프·로고·마무리), 반복 문구 자동 거르기 — (다음)
5. 마무리에 팬 질문 또는 지난 회 댓글 소개, 시리즈 번호 — (다음)
6. 대표 확인 → 확정 → 업로드

## 운영 방향 (대표 결정 2026-11-02 22:44)
- 유튜브 **수익화는 목표로 하지 않는다**. 영향력(구독·조회·유입)을 키워 부가 효과를 노린다.
- 단, 저작권 신고(삭제·경고, 3번이면 채널 삭제)는 수익화와 별개 → 공식 채널·공식 자료만, 출처 표기는 그대로 지킨다.

- 기준 B "한 장면형": 리마인드 「[리센느] 쇠맛 춤추는 메이x미나미」 youtube.com/shorts/56-QmKjSECg (79만, 9/1, 약 24초)

공통 틀
1. 상단 제목 2줄 고정: 1줄 "~다는" 소문형 궁금증(초록 띠 또는 흰색) + 2줄 대상(흰색 또는 노랑). 우리 hypeDRIP 제목 띠 그대로.
2. 가운데 원본 화면(자르지 않음), 위아래 검정 여백.
3. 출처: A형은 장면마다 화면 아래 "출처: ○○ 공식", B형은 설명란에 원본 링크·날짜.
4. 길이 25~45초, 원본 소리 유지, 음량 약 -23 LUFS.

A형 이야기형 (기본)
- 공식 영상 5~7개를 약 5초씩, 장면마다 노란 자막 한 줄로 이야기를 잇는다 (예: "얼마 전 삼성 광고에 이어" → "이번엔 디즈니" → "세계정복이 얼마 안 남았다는데").
- 우리 차별점: 확인된 사실만 자막으로, 끝에 '이슈브리프 한 줄', 확정된 엔딩 화면(로고+구독 유도).

B형 한 장면형
- 공식 클립 1개 통째 + 필터(예: 흑백) + 상단 제목만. 설명란 "한 번 더 보는 걸 추천" 같은 한마디.
- 우리 쪽은 엔딩 화면 또는 한 줄 코멘트를 붙여 그냥 옮겨 올린 느낌을 피한다.
