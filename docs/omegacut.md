# 오메가컷 (OmegaCut) — 우리만의 롱폼 → 요약 쇼츠 도구
이름·방향: 대표 결정 2026-11-02 14:18~14:20. 알파컷 같은 자동 편집을 벤치마킹하되 "양산형 느낌을 지우고 사람의 정성이 들어가게".

## 원칙
- 허락받은 영상만 넣는다(유튜브 자동 다운로드는 하지 않음 — 약관·차단). 추가 비용 0원.
- AI는 초안, 장면 선택과 '이슈브리프 한 줄'은 사람(대표)이 정한다.
- 음악은 수노 구독 중 만든 9곡(해지 후에도 권리 유지, 결제 영수증 보관) + 합성곡.

## 단계
1. 후보 뽑기 `scripts/pick_scenes.py <영상> <폴더>` — 소리 크기·갑자기 커짐·장면 전환 밀도로 후보 10개 + 번호 붙은 모음 이미지(sheet.jpg). ✅ 1차 완성(11/2)
2. 대표가 휴대폰에서 번호 5~7개 선택 + 장면마다 '이슈브리프 한 줄'(확인된 사실) — (다음)
3. 이야기 순서로 이어 붙이기: 궁금증 → 장면들 → 마지막 한 방 — (다음)
4. 쇼츠 기본 틀 입히기(두 줄 제목·노란 자막·양옆 글자·테이프·로고·마무리), 반복 문구 자동 거르기 — (다음)
5. 마무리에 팬 질문 또는 지난 회 댓글 소개, 시리즈 번호 — (다음)
6. 대표 확인 → 확정 → 업로드
