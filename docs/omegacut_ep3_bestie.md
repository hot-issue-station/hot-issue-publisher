# 덕심저장소 3편 — 베스티 「연애의 조건」 (목 11/5, 대표 확정 11/3 18:23)

각도: **'다시 불려 나온 노래'** — 2편 유스피어('빛 못 본 팀에 찾아온 기회')와 겹치지 않게, 이번엔 '노래가 사람들을 다시 불러 모은 이야기'.

## 확인한 사실 (직접 연 기사·차트)
- 2013년 발표한 두 번째 싱글. 활동 당시엔 차트에 오르지 못함 (코리아타임스 2026.09.16)
- 2018년 공식 해체 (스포츠경향 영문 2026.10.29)
- 시작: 5월부터 숏폼에서 화제 → 7월 말 하츠투하츠 '레몬탱' 안무 + 이 노래를 섞은 팬 영상('레몬탱 행진')이 퍼짐 (더팩트 2026.10.06, 코리아타임스)
- 리센느·최예나·엔믹스·투모로우바이투게더가 원곡 챌린지에 참여 (더팩트) ← 리센느 연결고리
- 숏폼 수(9/28 기준): 유튜브 쇼츠 약 3만, 틱톡 약 57만, 인스타 릴스 약 4만 (더팩트)
- 멜론 일간 첫 진입 8/27 (코리아타임스) → 멜론 TOP100 최고 64위 9/28 (더팩트) → 오늘 11/3 멜론 TOP100 18:00 14위, 19:00 18위 (직접 확인)
- 애플뮤직 한국 TOP100 7위, 유튜브 쇼츠 일간 2위, 샤잠 한국·베트남 1위 (더팩트·코리아타임스)
- 10/17 재결합 발표, 4인(혜연·해령·유지·다혜) 연습 시작 → 10/31 MBC '쇼! 음악중심', 4인 완전체 무대는 11년 만 (스포츠경향 영문 10/29)
- 유지: "이렇게 늦게 차트에 오를 줄 몰랐다"는 취지의 SNS 소감 (코리아타임스 — 원문 확인 후 인용)
