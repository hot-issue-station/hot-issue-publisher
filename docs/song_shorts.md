## 원칙
- 속도가 생명: 방송·공개 직후 가장 빨리 만들어 올린다(알고리즘도 빠른 게시가 유리).
- 한 곡 = 한 편. 여러 곡이면 1편 완성 → 바로 업로드 → 2편 작업 → 완성 → 이어서 업로드 순서로 간다.
- 하이라이트 구간은 끊지 않고 연속으로 들려준다. 끝에는 "전곡은 원본에서"를 안내한다(원본 채널·회차 표기, 설명란에 원본 링크).
- **유튜브 쇼츠는 전체 58초**(노래 54.5초 + 마지막 안내 3.5초). 저작권 음악이 들어간 쇼츠가 60초를 넘으면 유튜브가 차단한다(11/4 64초로 올려 두 편 모두 차단됨). 틱톡·인스타·X는 같은 파일을 쓴다.
- 공식 채널 영상만 쓴다. 출처는 영상 위쪽 오른쪽과 설명 두 곳에 표시한다(원본 가사 자막을 가리지 않게).
- 원본 가사 자막은 그대로 살리고, 가사는 번역하지 않는다(저작권). 일본어는 제목 띠, 댓글 상자 번역, 마지막 안내에 넣는다.

## 만드는 순서
1. 원본 확인: 설명란 타임라인으로 곡 시작 시각을 찾는다. 인기 댓글을 모은다.
2. 녹화: 노트북 OBS(크롬 창 캡처). 재생 직전 분홍 화면 0.4초 표시. 광고는 '건너뛰기' 버튼을 찾아 누른다. 녹화 중에는 다른 탭을 화면에 띄우지 않는다(창 캡처가 바뀜).
3. 하이라이트 찾기: 1초 단위 소리 크기 + 장면 확인으로 후렴·고음이 들어간 구간을 고른다.
4. 렌더 → 대표에게 공유 → 대표가 확정 → 업로드. 업로드할 때 첫 댓글도 단다(유튜브는 고정, 인스타는 한 번만). 첫 댓글에는 곡에 맞는 질문, 매너 있는 댓글 부탁, 전곡은 원본에서, 구독·좋아요·알림을 넣는다.
5. 업로드 파일은 10MB 미만으로 다시 압축한다(1100k). outbox/<날짜>_<이름>/reel.mp4
