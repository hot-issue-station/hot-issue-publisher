## 4. 영업용 QR 활용법

1. 설치 페이지 주소가 정해지면 QR을 만든다(인터넷·비용 없이, 공장에 있는 생성기):
   ```
   cd factory && python3 -c "from qr import qr_image; qr_image('(설치 페이지 주소 자리)', scale=12, border=4).save('salon_qr.png')"
   ```
2. 쓰는 곳
   - **명함 뒷면·A6 안내 카드**: 「휴대폰 카메라로 찍으면 바로 설치 화면」 + QR + 「무료 · 손님 기록은 원장님 휴대폰 안에만」
   - **매장 방문 때**: 종훈 휴대폰 화면에 QR을 띄워 원장님 휴대폰 카메라로 찍게 → 그 자리에서 설치(1번 설명서 「처음 설치하기」)
   - **SNS**: 인스타 카드 마지막 장·당근 소식 이미지·블로그 글 맨 아래
3. 어디서 설치했는지 보려면 주소 뒤에 `?from=jonghun`·`?from=insta` 같은 꼬리표를 붙여 QR을 따로 만든다(설치 페이지가 이 꼬리표를 세는 기능은 **아직 없음** — 생기기 전까지는 원장님께 "어디서 보셨어요?"를 여쭤 기록).
4. 인쇄는 집·사무실 프린터로(비용 0원 원칙). QR 아래에 주소 글자도 함께 적어 카메라가 안 될 때 대비.

## 5. 종훈 매장 방문 영업 스크립트 (1분)

> 바쁜 시간(오후 손님 많을 때)은 피하고, 손님이 없을 때 들어간다. 원장님이 바쁘시면 안내 카드만 드리고 나온다.

- **(0~10초) 인사** — "안녕하세요, 원장님. 근처에서 동네 미용실용 손님 기록 앱을 만들어 무료로 설치해 드리고 있어요. 1분만 보여 드려도 될까요?"
- **(10~25초) 문제** — "혹시 손님 기록 수첩에 하세요? 지난번 염색 몇 호였는지, 언제 오셨는지 찾기 번거로우시죠."
- **(25~45초) 보여 주기** (휴대폰으로 「단골 수첩 3분 사용법」 앞부분 또는 직접 화면) — "이름이나 번호 뒷자리 누르면 바로 나오고요, 시술 누르면 금액이 저절로 들어가요. 오래 안 오신 손님은 알려 줘서 문자 한 번이면 돼요. 글씨도 크게 만들었어요."
- **(45~55초) 안심** — "돈은 안 받아요. 앱 안에 광고라고 표시된 추천 상품 칸이 있어서 그걸로 운영해요. 손님 기록은 원장님 휴대폰 안에만 저장되고, 저희도 못 봐요."
- **(55~60초) 다음 걸음** — "지금 QR 찍으시면 10분 안에 설치해 드리고, 쓰시던 손님 목록도 옮겨 드릴게요. 아니면 이 카드 두고 갈게요."

하지 말 것: "매출이 ○% 오릅니다" 같은 근거 없는 약속, 다른 앱 깎아내리기, 원장님 휴대폰 속 손님 정보를 대신 보거나 가져가기(설치·옮기기는 원장님이 보시는 앞에서 원장님 휴대폰에서만).

## 6. 원장님 후기 받는 법 (가짜 후기 금지)

원칙: **실제로 써 보신 원장님의, 실제 말만.** 지어낸 후기·여러 계정 돌려 쓰기·대가(선물·돈)를 주고 받은 후기를 숨기는 것은 하지 않는다(공정위 추천·보증 심사지침, 각 플랫폼 정책). 대가를 드렸다면 후기에 「소정의 ○○을 받았어요」를 꼭 적는다.

1. **2주 이상 쓰신 원장님께만** 여쭌다: "써 보시니 어떠세요? 좋았던 점·불편한 점 다 괜찮아요."
2. 불편한 점은 개발(대표)에 넘기고, **좋은 말만 골라 싣지 않는다**(불편한 점 고친 이야기도 콘텐츠가 됨).
3. 싣기 전에 아래 동의를 받는다(카카오톡으로 받아 캡처 보관, 또는 종이에 서명).
4. 원장님 얼굴·가게 간판·손님이 나오는 사진은 **동의한 것만**, 손님 얼굴·이름·전화번호가 보이는 앱 화면은 **절대 싣지 않는다**(앱 화면은 가짜 손님 화면으로 대신).
5. 원장님이 내려 달라고 하시면 **바로 내린다**(3일 안).

## 7. 플랫폼 정책상 주의점 (짧게)

| 구분 | 주의할 점 |
|---|---|
| 공통 — 광고 표시 | 우리 서비스를 우리 계정에서 소개하는 것은 누가 올렸는지 분명하므로 따로 '광고' 표시는 필요 없지만, **후기처럼 꾸미지 않는다.** 남에게 대가를 주고 올리게 하면 「광고」「협찬」을 글 첫머리에 표시(공정위 추천·보증 심사지침). 앱 속 추천 상품 칸이 제휴 링크라는 것도 숨기지 않는다 |
| 공통 — 개인정보 | 실제 손님 정보가 담긴 화면은 절대 쓰지 않는다(영상·그림은 시험용 가짜 손님만). 원장님 얼굴·가게는 동의서 받은 것만 |
| 공통 — 광고성 메시지 | 원장님께 DM·문자·카톡 메시지를 **먼저 일괄로 보내지 않는다**(정보통신망법상 광고성 정보는 사전 동의가 필요하고 (광고) 표시가 필요). 먼저 연락해 온 분께 답하는 것은 괜찮음 |
| 인스타그램 | 유료 협업이면 '유료 파트너십' 표시 기능 사용. 같은 문구·해시태그 대량 반복, 팔로우·좋아요 품앗이·구매 금지(노출 제한) |

| 네이버 블로그 | 대가성 글은 경제적 이해관계 문구 필수. 같은 글 복사·키워드 반복은 저품질 처리 위험 |
| 당근 비즈프로필 | 동네 이웃 대상 서비스 성격에 맞게. 동네생활 게시판에 홍보 글 올리지 않기(비즈프로필 '소식'만). 유료 광고 안 씀 |
| 카카오톡 채널 | 채널 개설·1:1 채팅은 무료, **친구에게 보내는 메시지 요금·무료 범위는 개설 전 확인 필요**. 광고 메시지는 (광고) 표시 |

## 8. 만드는 법 (공장 명령)

```
# 사용법 영상·소개 쇼츠·설명서 그림 다시 만들기 + 「기능 30초 소개」 클립·채우기 파일
python3 salon/docs/make_video.py --factory-clips factory/templates_salon/fills/기능소개_클립

# 편성표 보기 (월·수·금 아침)
cd factory && python3 make_today.py --templates-dir templates_salon --list

# 렌더 + 게시 꾸러미(인스타·유튜브·스레드 글 포함, 올리지는 않음)
python3 make_today.py --templates-dir templates_salon --day 수 --slot 아침 --fill templates_salon/fills/fill_수_기능소개.json --package
python3 make_today.py --templates-dir templates_salon --day 월 --slot 아침 --fill templates_salon/fills/fill_월_꿀팁.json --package
python3 make_today.py --templates-dir templates_salon --day 금 --slot 아침 --fill templates_salon/fills/fill_금_숫자.json --package
```
- 꾸러미에는 tiktok.txt·x.txt도 함께 생기지만, 미용실 홍보 계획에서는 **인스타·유튜브·스레드**만 쓴다.
- 업로더 계획은 기본 유튜브만(확인 모드, 최종 [예약] 버튼은 대표가 직접).
