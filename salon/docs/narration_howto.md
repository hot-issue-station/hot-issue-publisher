# 단골 수첩 사용법 영상 — 내레이션 대본 (Veda)

> `make_video.py --narration-md` 로 만들어진 문서예요. 대본을 고치려면 make_video.py 의 `NARR_HOWTO`·`NARR_TEASER` 를 고친 뒤 다시 만들어 주세요(영상과 대본이 어긋나지 않게 한 곳에서만 관리).
> 앱 v3.1 실제 화면 글자와 맞췄어요. 화면 속 손님은 모두 시험용 가짜 이름이에요.

## 목소리 설정 (Google AI Studio · 무료)

- 목소리: **Veda** (여성) — 남성이 필요하면 Finn
- 스타일 지시(Style instructions 칸에 그대로): `따뜻하고 또박또박, 동네 미용실 원장님께 옆에서 차근차근 알려 드리듯 읽어 주세요. 조금 천천히, 문장이 끝날 때마다 1초쯤 쉬어 주세요.`
- 한 번에 덩어리 하나(500자 안팎)씩 붙여 넣고, 받은 파일 이름을 아래 **파일 이름** 그대로 바꿔 한 폴더에 모아 주세요.
- 문장 사이를 1초쯤 쉬어야 영상 프로그램이 문장별로 정확히 잘라요(쉼표 쉼은 짧아서 안 잘려요).

## 사용법 영상 (세로 1080×1920 · 13단계)

장면 key → 영상 단계: setup=1. 처음 한 번만 · today=2. '오늘' 화면 · newcust=3. 새 손님 등록 · record=4. 시술 기록 · voice=5. 말로 기록 · search=6. 손님 찾기 · import=7. 연락처·엑셀 불러오기 · group=8. 단체 문자 도우미 · sms=9. 다시 오실 때 알림 · booking=10. 예약 잡기 · sales=11. 매출 보기 · backup=12. 일주일에 한 번 백업 · color=13. 염색 미리보기 · intro=제목 화면 · outro=끝 화면

## 15초 소개 쇼츠

장면: intro=첫 화면(질문) · record=시술 기록 · sms=다시 오실 때 · sales=매출 · outro=끝 화면. 내레이션이 15초보다 길면 쇼츠가 그만큼 늘어나요(지금 대본 기준 약 15~17초).

## 영상 만들기

```
python3 make_video.py --narration-dir 내레이션폴더
```

- 폴더에 `n01.wav`~`n03.wav`(사용법), `t01.wav`(쇼츠)가 있으면 넣고, 없으면 그 부분은 지금처럼 자막만 나와요.
- mp3·m4a 로 받았어도 같은 이름이면 돼요(예: n01.mp3).
- 문장별로 자른 결과는 결과 폴더 `_narration/문장_자른결과.json` 에 남아요(문장 길이 확인용).
