## 갤러리 반영 (2026-11-11)
- hall.html 설정 `ENDORSEMENTS`에 '현재' 11곳(도미노피자·CU·나랑드사이다·할리스·카사베르디·엘리트학생복·우리은행·MLB·에이페·한스킨·티오더)을 넣었다.
- 보이는 곳: 모든 방 뒤 벽 「리센느 공식 광고 모델」 판(브랜드 이름 판 + 한 줄, 누르면 출처 기사 버튼), 굿즈 샵 「광고 제품」 구역. 로고·사진 없이 글자 판만, 「유료 광고 아님 · 정보」 표시. 영상 패널 안에는 넣지 않음(YouTube API 정책 III.G).
- 방별 앞줄 순서는 `ENDORSEMENTS.order`(무대=패션·뷰티, 일상=카페·편의점, TV=TV 광고, 안원잘부=우리은행 등)에서 바꾼다.
- 우리은행 메이킹 필름(spN_ZVoONdg)은 「광고관 코너」 카드 → 일반 영상 패널로 재생.
- FC 모바일은 `enabled:false`(대표 결정 대기). KGB(주류)·근거 부족(unclear) 항목은 넣지 않음.
- 안원잘부 공식 굿즈: `SHOPS`의 `anwonjalbu_store.store_url`(지금 null → 「공식 굿즈 링크 준비 중」). 제휴 링크 아님 표시.
