| 퀴즈·미션 화면 | 출처·확인 날짜가 있는 퀴즈만 화면에 나온다(갤러리 안전장치 그대로). 비밀의 방 보상 영상도 공식 채널 공개 영상만. |
| 광고·제휴 | 굿즈 샵 장면에서 「광고」·대가성 문구가 화면에 보이게 찍는다(가리지 않기). |

## 5. 촬영 방법

### A. 자동 녹화 (이 환경 · 지금 되는 것)
- `make_gallery_video.py`가 갤러리를 로컬 서버로 열고 Playwright(크로미움)로 누르며 녹화 → 자막 띠 얹기 → mp4.
- three.js(3D 엔진)는 이 환경에서 jsdelivr를 못 받으므로, 미리 받아 둔 같은 판(r186)을 가로채 넣는다: `--three-dir <three build 폴더>` (scratchpad `sky_chk.py`·`chk4.py` 의 `page.route("https://cdn.jsdelivr.net/npm/three@0.186.1/build/*", …)` 방식 그대로). 인터넷 되는 PC에서는 이 옵션 없이 돈다.
- 3D는 소프트웨어 그래픽(swiftshader)이라 프레임이 조금 거칠 수 있음 → 최종본의 3D 장면도 집 PC에서 찍으면 더 부드럽다.
- 카메라 움직임은 `Gallery._debug.yaw/pitch` 를 천천히 바꿔서(`pan()`), 장소 이동은 `Gallery.go(view, 관, 방)`.
- 녹화 전 정리: ① 위쪽 「AD 광고 자리」 띠와 공중의 「AD SPACE」 빈 광고판이 그대로 찍힌다(아래 11-11 시험 화면) — 광고가 실제로 붙은 뒤 찍거나, 빈 자리 표시를 끄는 시험용 주소 옵션을 갤러리에 만들지 대표 결정. ② 방은 차례로 열리는 구조(🔒)라, 뒤쪽 방 장면은 시험용 진행 기록을 채워 문을 연 상태로 찍는다(시청자에게는 「차례로 열려요」라고 설명).
- 장면 더하는 법: `SCENES` 에 한 줄 + 동작 함수 하나. 예) 퀴즈 `page.evaluate("Gallery.startMission(Gallery.missions('rescene','stage')[0])")`, 굿즈 샵 `Gallery.go('shop','rescene')`, 언어 `page.select_option('#langSel','ja')`, 영상 창 `Gallery.openItem({...})`/`Gallery.closeItem()`.

### B. 집 PC 크롬 + OBS (더 나은 장면)
| 장면 | 이유 |
|---|---|
| frame · react(위쪽) · p_frame · ③ 0:07 | 유튜브 썸네일·임베드가 이 환경에서 막힘(액자가 「곧 채워져요」처럼 비어 보임) |
| secret 보상 영상 재생 | 같은 이유 |
| shop 상품 사진 | 외부 사진이라 막힐 수 있음 |
| (선택) 3D 걷기 장면 전부 | 진짜 그래픽 카드라 더 부드러움 |

OBS 설정(무료): 해상도 1920×1080, 30fps, 녹화 형식 mp4(또는 mkv 후 변환), 소리 「데스크톱 오디오」 끄기(공식 영상 소리 안 넣음). 크롬 창은 F11 전체 화면, 쇼츠는 개발자 도구 휴대폰 화면(390×844)으로. 찍은 파일은 `gallery/docs/obs/frame.mp4` 처럼 장면 key 이름으로 두면 나중에 스크립트가 그 장면만 바꿔 끼우게 만들 예정(지금 뼈대에는 없음).
